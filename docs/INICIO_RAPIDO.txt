Digite:
  python verificar_ambiente.py

Deve aparecer ✓ em tudo (Python, arquivos, dependências, PyInstaller).

Se aparecer ❌ em algo → Siga as instruções mostradas.

  python build_exe.py

Aguarde 5-15 minutos.

  dist/Grafo de Colaboracao.exe  (~150 MB)

✓ PRONTO! Clique no .exe para rodar. Sem Python necessário!
